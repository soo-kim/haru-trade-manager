# Engineering Backlog (v0.1)

## 1. 목적

이 문서는 구현 시작을 위한 작업 티켓 초안이다. 각 항목은 독립적으로 진행 가능하도록 범위와 완료 조건을 포함한다.

## 2. 에픽과 작업 항목

### EPIC-A 프로젝트 부트스트랩

`A-1` 저장소 기본 구조 생성
- 범위: `app/`, `tests/`, `migrations/`, `scripts/` 디렉토리 생성
- 완료 조건: 실행 진입점 1개와 테스트 실행 스크립트 준비

`A-2` Docker Compose 기본 스택
- 범위: `app`, `postgres`, 볼륨/환경변수 정의
- 완료 조건: 로컬에서 DB 연결 가능한 상태

`A-3` CI 기본 검사
- 범위: 린트, 타입체크, 단위테스트 최소 파이프라인
- 완료 조건: PR마다 자동 실행

### EPIC-B 데이터/영속 계층

`B-1` DB 스키마 v1 설계
- 범위: symbols, candles, positions, orders, configs, config_history, snapshots, cash_flows
- 완료 조건: Alembic 마이그레이션 1회로 생성 가능

`B-2` 캔들 저장소(Repository) 구현
- 범위: 마지막 봉 조회, 마지막 봉 UPDATE, 신규 봉 INSERT
- 완료 조건: 증분 동기화 테스트 통과

`B-3` 인덱스/제약 조건 적용
- 범위: 캔들 PK(종목+타임프레임+기준시각), 주문 조회 인덱스
- 완료 조건: 중복 봉 방지 확인

### EPIC-C 코어 런타임

`C-1` ConfigManager 구현
- 범위: get/set/검증/DB 동기화/변경 이벤트
- 완료 조건: 범위 검증 및 재시작 복원 테스트 통과

`C-2` RateLimitedClient 구현
- 범위: 요청 간격 0.2초, 락, 우선순위 큐, 토큰 캐시
- 완료 조건: 동시성 테스트에서 정책 보장

`C-3` 서버시간 동기화 모듈
- 범위: offset 계산/저장/재동기화/오류 시 fallback
- 완료 조건: 마감 시각 판정 테스트 통과

### EPIC-D 매매 엔진

`D-1` 전략 인터페이스 및 인스턴스 레지스트리
- 범위: 공통 입력/출력 계약, active_hours 체크
- 완료 조건: 전략 mock 2개 등록/실행 검증

`D-2` 루프 B 구현
- 범위: 봉 마감 감지 -> 캔들 업데이트 -> 전략 실행 -> 시그널 큐 적재
- 완료 조건: 타임프레임별 트리거 테스트 통과

`D-3` 루프 A 구현
- 범위: 시그널 큐 소비, 주문 실행, 포지션 모니터링/청산
- 완료 조건: OPEN/HALF_CLOSED/CLOSED 전이 테스트 통과

`D-4` 리스크 엔진 구현
- 범위: ATR 사이징, max_positions, daily_loss, stop_count
- 완료 조건: 차단/정지 조건 테스트 통과

`D-5` 15:20 강제청산 루틴
- 범위: 계좌 레벨 재계산 + 우선순위 청산
- 완료 조건: 중단 조건/전량 조건 분기 테스트 통과

### EPIC-E 주문/외부 연동

`E-1` 주문 실행기
- 범위: 진입 지정가, 익절/손절 시장가, 주문 조회/재시도
- 완료 조건: 실패-조회-재시도 시나리오 테스트 통과

`E-2` 키움 API 어댑터
- 범위: 인증, 시세/캔들, 주문, 계좌 조회 API 래핑
- 완료 조건: 모듈 단위 모킹 가능

`E-3` 텔레그램 봇
- 범위: 알림 템플릿, 명령 파서, confirm 플로우
- 완료 조건: 핵심 명령(`status`, `set`, `pause`, `resume`) 동작

### EPIC-F 운영/관측/보고

`F-1` 구조화 로깅
- 범위: JSON 포맷터, 레벨 제어, 로테이션
- 완료 조건: 필수 이벤트 로깅 포인트 충족

`F-2` 성과 계산(TWR)
- 범위: cash_flows 반영 구간 수익률 계산기
- 완료 조건: 샘플 케이스 재현 정확도 확인

`F-3` 일일 리포트 생성
- 범위: 장 종료 요약, 전략별 성과, 리스크 이벤트 요약
- 완료 조건: 텔레그램 전송 확인

### EPIC-G 백테스트/페이퍼

`G-1` 백테스트 코어
- 범위: N봉 신호, N+1 시가 체결, 수수료/슬리피지 강제
- 완료 조건: 무결성 규칙 위반 테스트가 실패하도록 보장

`G-2` 페이퍼 모드
- 범위: 주문 레이어 모드 분기 + paper_* 테이블
- 완료 조건: live 코드 경로 변경 없이 paper 실행 가능

`G-3` 합격 판정기
- 범위: 승률/Sharpe/MDD/오류율/포지션 불일치 기준 계산
- 완료 조건: `/paper_report`용 결과 객체 생성
